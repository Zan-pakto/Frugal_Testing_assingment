## Section Overview

1. **Q1: Dynamic HTML5 Canvas State Drift & Asynchronous Race Interception**
   - Local canvas application powered by WebSocket updates.
   - Playwright automation utilizing `requestAnimationFrame`, color transitions, and coordinates calculation.
   - Dynamic race condition handling, hovering/dragging, WebSocket interception, latencies, and corrupted state injection.

2. **Q2: Cryptographic Replay Testing, Stateful Nonces & Hash Chain API Chaining**
   - Express.js Mock Transaction Server validating HMAC, Timestamp, and Nonces.
   - Axios-based API automation, replay protection verification, and detection of vulnerabilities.

3. **Q3: Shadow DOM Pathfinding & Accessibility Tree Refactoring**
   - Shadow DOM traversal utility using accessibility tree roles and ARIA properties.
   - Expert AI System Prompt for locate-only-via-accessibility-tree interaction.
